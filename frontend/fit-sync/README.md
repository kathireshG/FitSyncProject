# FitSync frontend

The FitSync React frontend is built with Vite and preserves the original
application interface.

```powershell
npm install
npm run dev
```

The development server runs at `http://localhost:5173` and expects the API at
`http://localhost:4000` by default. Override it with `VITE_API_URL` in a local
`.env` file.

```powershell
npm test
npm run build
npm run preview
```
